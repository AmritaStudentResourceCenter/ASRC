Roadmap

Project Timeline

Our journey from an idea to a fully functioning student ecosystem.

PHASE 1

Idea Created

Identified core student struggles in obtaining centralized notes.

PHASE 2

Repo Initialized

Created the open-source GitHub organization & architecture.

PHASE 3

UI/UX Development

Designed retro-modern glassmorphism design system.

PHASE 4

Lecture Notes Added

Cataloged verified lecture notes across all engineering departments.

PHASE 5

Syllabus Integration

Added up-to-date curriculum outlines for quick reference.
